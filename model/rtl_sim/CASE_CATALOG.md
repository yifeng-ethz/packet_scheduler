# RTL loss-sweep case catalog

This catalog defines the HDL-simulation closure step after the analytical and
TLM tiers. Every promoted RTL loss point must be generated by HDL simulation,
not by reusing analytical or TLM loss values.

## Variables

| variable | values | source |
|---|---:|---|
| `N_LANE` | `4`, `8`, `16` | OPQ native-SV build and old time-merger lane-count define |
| `egress_symbols_per_beat` | `1`, `2`, `4`, `8` | OPQ egress-width build; time-merger remains one-word |
| `B` | sampled over `[-0.25, 0.95]` | `B=(SCV-1)/(SCV+1)` |
| `rho_lane` | sampled over `[0.005, 0.30]` | offered hit rate per lane |
| `ready_duty` | sampled over `[0.45, 1.0]` | egress ready vacation profile |

## Required CSV Schema

| column | definition |
|---|---|
| `case_id` | stable case identifier from this catalog |
| `implementation` | `opq` or `time_merger` |
| `n_lane` | HDL lane count |
| `n_shd` | OPQ shadow-window point; `0` for time-merger if not applicable |
| `egress_symbols_per_beat` | OPQ egress width in 36-bit ingress symbols, or `1` for time-merger |
| `burstiness_b` | `B=(SCV-1)/(SCV+1)` |
| `rho_lane` | offered rate per lane |
| `ready_duty` | egress ready duty |
| `offered_hit_count` | legal hit words driven into the tested RTL input side |
| `delivered_hit_count` | legal hit words observed on the RTL output side |
| `dropped_hit_count` | DUT drop counter, or scoreboard missing hits for the standalone time-merger run |
| `loss_probability` | `dropped_hit_count / offered_hit_count` |
| `seed` | deterministic traffic seed |
| `warmup_cycles` | discarded warm-up interval |
| `measured_cycles` | post-warm-up measurement interval |
| `log_path` | source simulation log |

## Initial Closure Sequence

| case_id | tier tags | scope | implementation target | purpose |
|---|---|---|---|---|
| `RTL-LS-001` | `T,S,C` | `N_LANE=4`, `E=1x`, ready/burst grid at `rho_lane=0.0075` | OPQ native-SV and old time-merger | prove the low-feature point where OPQ should already win under burst or ready deassertion |
| `RTL-LS-002` | `T,S,C` | `N_LANE=4`, `E=1x`, burst/rate grid at `ready_duty=1.0` | OPQ native-SV and old time-merger | promote the loss-surface contour from model to HDL evidence |
| `RTL-LS-003` | `T,S,C` | `N_LANE=8`, `E=2x`, ready/burst grid at `rho_lane=0.0075` | OPQ native-SV and old time-merger | verify the first higher-lane scaling point |
| `RTL-LS-004` | `T,S,C` | `N_LANE=16`, `E=4x`, ready/burst grid at `rho_lane=0.0075` | OPQ native-SV and old time-merger | verify high-lane scaling before widening to all egress points |
| `RTL-LS-005` | `T,S,C` | all `N_LANE={4,8,16}`, `E={1,2,4,8}` stress point | OPQ native-SV and old time-merger | generate the feature-scaling heatmap from HDL counters |

## Promotion Rule

A plotted RTL loss point is promoted only when both the OPQ and time-merger
entries exist for the same variable tuple, both simulations pass protocol
checks, and the plotted `loss_probability` is computed from the HDL counters in
the required CSV schema.
