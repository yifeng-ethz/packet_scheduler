# MODEL_REPORT.md - packet_scheduler OPQ model publish report

This report centralizes the MODEL_PUBLISH figure set. Analytical rows are the architecture baseline; TLM rows are executable model evidence; RTL SIM rows are generated by `rtl_sim/scripts/run_model_publish_rtl_sweep.py`; the board tier remains explicitly tagged as pending until on-board CSVs land.

Shared equations: burstiness is $B=(CV_{timestamp}-1)/(CV_{timestamp}+1)$ from hit-to-hit true generation interevent times, where $CV_{timestamp}=\sigma_\tau/m_\tau$ and $SCV_{timestamp}=CV_{timestamp}^2$; the effective load is $\rho_{eff}=(N_{LANE}\rho_{lane}/(E\,q))\sqrt{(1+SCV)/2}$; finite-buffer loss is approximated by $P_K=((1-\rho_{eff})\rho_{eff}^{K})/(1-\rho_{eff}^{K+1})$; OPQ gain is $G=P_{loss,TM}/P_{loss,OPQ}$; ready duty is $q=H/(H+L)$.
