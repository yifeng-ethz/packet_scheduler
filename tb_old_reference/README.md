# Old Time-Merger Reference

This folder holds a standalone SystemVerilog reference model for the historical
MuSiP SWB time-merger architecture.  The source inspected for this comparison
was:

- `https://github.com/makoeppel/musip/blob/main/firmware/a10_board/a10/swb/time_merger.vhd`
- `https://github.com/makoeppel/musip/blob/main/firmware/a10_board/a10/swb/time_merger_tree.vhd`
- local clone commit `785f4558f6d5eec16f2acd3c14abbd8efe9da5b7`

The model in `rtl/old_time_merger_ref.sv` is not pin-compatible RTL and is not
wired into the old SWB datapath.  It does, however, parse the exact OPQ/FEB
36-bit frame-word format used by the live UVM ingress driver:

- preamble: `datak=1`, SOP, `K28.5`
- timestamp/header words: the four OPQ auxiliary words after the preamble
- subheader: `datak=1`, `K23.7`, with the OPQ subheader timestamp and hit count
- data hit: `datak=0`
- trailer: `datak=1`, EOP, `K28.4`

It keeps the behavior that matters for the OPQ comparison:

- structural phases such as SOP, timestamp words, subheaders, and EOP are
  join-gated across all active lanes
- payload/data words are passed one lane per accepted output beat
- merged OPQ debug-header and subheader hit-count fields are recomputed so the
  output stream remains parseable as the same packet format
- the hit selector can run as round-robin for the comparison requested here or
  in timestamp-nibble priority mode, matching the old tree file more closely

The standalone smoke test uses the same OPQ packet helper semantics as
`tb/uvm/opq_pkg.sv` and the UVM ingress driver: preamble, four frame-header
words, subheader, data hits, and trailer are generated as 36-bit `datak+data`
words. This keeps the old reference comparable without wiring it into the
historical SWB datapath.

The original tree variant builds 2-input merger layers and inserts a FIFO at
each layer output.  This reference now builds the same stage-buffered 2-input
cascade for `N_LANE=4/8/16`.  Each stage adds another join point, an
inter-stage FIFO, and another one-beat-at-a-time payload service point.

Plot data under this folder must be generated by RTL simulation.  Earlier
analytical/proxy CSVs in `REPORT/` are retained only as stale development
artifacts and must not be used as evidence for the math report.

Run the standalone simulation smoke from this directory with:

```sh
make smoke
```

Run all direct standalone exact-frame lane-count screens with:

```sh
make smoke-all
```

Current direct evidence:

- `LANE_COUNT=4`: one merged header, one merged subheader, `8` hits, one trailer
- `LANE_COUNT=8`: one merged header, one merged subheader, `16` hits, one trailer
- `LANE_COUNT=16`: one merged header, one merged subheader, `32` hits, one trailer

Formal scope:

- `formal/old_time_merger_ref_formal_tb.sv` constrains legal OPQ-word sidebands
  and ready/valid stability
- the embedded assertions target output stability under backpressure, legal
  lane-ready behavior, masked-lane containment, and parseable SOP/EOP output

Run from this directory with:

```sh
cd formal
sby -f old_time_merger_ref.sby prove
sby -f old_time_merger_ref.sby cover
```
