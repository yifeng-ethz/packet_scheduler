# packet_scheduler math report artifacts

The residency-proxy artifacts in this directory are parsed from RTL simulation
logs and remain valid RTL-derived evidence for `MATH_REPORT.md`.

The `queueing_model/` subdirectory contains the reproducible analytical
queueing/network-calculus data grids. The published analytical figures are
rendered with DISLIN under `plots/analytical/`.

The `plots/` subdirectory separates published figures by evidence tier:
analytical, TLM, RTL simulation, and on-board measurement. Empty evidence tiers
contain status README files instead of copied or relabeled plots.

Loss-surface, lane-skew-loss, and OPQ lane/egress contour artifacts that were
generated by older analytical/proxy scripts directly in this directory are
stale development artifacts. Do not use those legacy plots as report evidence.
New RTL loss plots must still be rendered from HDL simulation tables supplied
explicitly to the render wrappers.
